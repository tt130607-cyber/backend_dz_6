CPU-bound vs I/O-bound

CPU-bound задача выполняет тяжёлые вычисления на процессоре.

Пример:
- большой цикл
- сложные вычисления

Во время CPU-bound задачи Event Loop блокируется.

Из-за этого:
- setTimeout срабатывает позже
- сервер не может обрабатывать другие запросы

I/O-bound

I/O-bound задачи:
- чтение файлов
- работа с сетью
- база данных

Node.js передаёт такие операции системе/libuv.

Event Loop не блокируется и может выполнять другие задачи.

Почему setTimeout сработал поздно

setTimeout был поставлен на 100ms.

Но тяжёлый цикл заблокировал главный поток.

Пока цикл не завершился, Event Loop не мог обработать timer callback.
