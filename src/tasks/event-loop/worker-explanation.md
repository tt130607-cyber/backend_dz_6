# Chunking vs worker_threads

## Chunking

Chunking делит большую задачу на маленькие части.

После каждого чанка используется setImmediate().

Плюсы:
- проще
- не создаёт новые потоки
- меньше потребление памяти

Минусы:
- всё ещё использует главный поток
- CPU всё равно нагружает Event Loop

## worker_threads

worker_threads создаёт отдельный поток ОС.

Тяжёлые вычисления выполняются отдельно от главного потока.

Плюсы:
- главный Event Loop не блокируется
- сервер отвечает быстрее
- лучше для тяжёлых CPU задач

Минусы:
- сложнее
- больше потребление памяти
- есть overhead на создание worker
