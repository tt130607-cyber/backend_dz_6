# Blocking Event Loop

Если выполнить тяжёлый цикл синхронно, Event Loop будет заблокирован.

Из-за этого:
- сервер не сможет обрабатывать другие запросы
- timers не будут выполняться
- приложение "зависнет"

# Решение через chunking

Большая задача делится на маленькие части.

После каждого чанка используется:

setImmediate()

Это позволяет:
- освободить Event Loop
- обработать другие запросы
- не блокировать сервер полностью

# Почему setImmediate помогает

setImmediate ставит выполнение в check phase Event Loop.

Между чанками Node.js может:
- обработать timers
- обработать I/O
- принять новые HTTP запросы
